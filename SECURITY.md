# Security

Report vulnerabilities privately to privacy@keysprig.xyz. Include reproduction steps using dummy data. Do not post credentials, real key values, personal records or exploitable production details in public issues.

The main branch is a beta reference implementation. There is no promised response SLA or completed independent security certification. Review the documented trust and outbound-network boundaries before deployment.

Keep service-role credentials, encryption roots, invitation codes, backups and runtime files private. If a credential is exposed, revoke or rotate it at its provider; deleting a Git commit does not revoke a credential.
