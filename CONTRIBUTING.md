# Contributing

Open an issue describing the problem, then submit a focused pull request with relevant verification. Run typecheck, tests and build before submitting. Keep private data, agent chat transcripts, credentials and deployment account identifiers out of commits and issues.

Maintain the use-only boundary: MCP must never return raw keys. Preserve owner isolation, exact destination policies, approval, revocation and audit behavior. New automatic provider presets must not expand permissions silently.

Contributions are provided under the repository's MIT license. Security findings should use the private reporting channel in SECURITY.md.
